# Results — Visual Walkthrough

> ⚠️ **Note:** This branch is not a standalone implementation. It is a visual walkthrough of the statistical tables and plots generated by the main pipeline. All actual working code lives in `main.py` of the `main` branch.

---

## Overview

This branch contains two notebooks that isolate and display the outputs of the pipeline:

- `Tables.ipynb` — reproduces all statistical tables from the analysis
- `Plots.ipynb` — reproduces all static plots and animated visualizations

Both notebooks load from `dataset_cleaned.csv` (already produced by the main pipeline) and show exactly how each result is computed and rendered.
